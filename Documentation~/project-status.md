## Status

Version `0.7.0`; UI Scroller was first released as 0.5.0. Its API and behaviour may still change before `1.0.0`. It's by a single author and isn't used in a shipped game yet. Planned work is in [Limitations and roadmap](troubleshooting.md#limitations-and-roadmap) and the [issues](https://github.com/sgonzalezrozo/unity-ui-scroller/issues).

## Versioning

Until `1.0.0`, a minor version (0.6, 0.7…) can include breaking changes; patch versions (0.5.1) never do. From `1.0.0` on, only major versions will. Breaking changes are marked **Breaking** in the [changelog](../CHANGELOG.md).

## Contributing

Bug reports and pull requests are welcome; please open an issue before a large change. See the [contributing guide](../.github/CONTRIBUTING.md) and the [security policy](../.github/SECURITY.md).
