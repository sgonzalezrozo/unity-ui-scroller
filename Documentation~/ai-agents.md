# AI Coding Agents

[← Back to README](../README.md)

Coding agents write C# files, and this package is newer than their training data. Copy [`agent-rules.md`](agent-rules.md) into your project's agent rules (`AGENTS.md`, `CLAUDE.md`, `.cursor/rules/ui-scroller.md`) so agents use the real API instead of guessing.

For a whole Unity architecture with a verify loop, add [Unity Architecture Agents](https://github.com/sgonzalezrozo/unity-architecture-agents).
